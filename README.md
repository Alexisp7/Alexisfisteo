# Blog de Física — Dr. A. Vargas

Sitio web personal de portafolio académico. Diseño elegante blanco con acentos dorados y toques griegos.

## Estructura de archivos

```
index.html          ← página principal
img/
  hero.svg          ← BEIGE DORADO    → reemplazar con tu foto principal
  about.svg         ← AZUL CLARO     → reemplazar con tu foto "Sobre mí"
  proj1.svg         ← VERDE MENTA    → QuantumSim (MIT Hackathon 2024)
  proj2.svg         ← ROSA           → GravLens (NASA SpaceApps 2023)
  proj3.svg         ← MORADO         → ParticleNet (CERN Datathon 2023)
  proj4.svg         ← NARANJA SUAVE  → TopologyViz (Hack UNAM 2022)
  proj5.svg         ← CELESTE        → PhysicsGPT (AI for Science 2022)
  proj6.svg         ← AMARILLO       → WaveSim (HackMIT 2021)
```

## Cómo reemplazar las imágenes

Sube tu imagen y renómbrala igual que el `.svg` que reemplaza, o edita el `src` en el HTML.
